## Featured Project

### Paskibra Selection Decision Support System

A web-based Decision Support System developed to support the selection of school-level Paskibra members in Tangerang
Regency using the **Fuzzy Sugeno method**.

**Key Features**
- Candidate assessment based on height, knowledge test scores, and interview results.
- Fuzzy Sugeno inference for candidate evaluation.
- Role-based access for administrators and participants.
- Database management using MySQL.
- Web application development using PHP and Bootstrap.

**Technologies:** PHP, MySQL, Bootstrap, JavaScript, Fuzzy Sugeno.
